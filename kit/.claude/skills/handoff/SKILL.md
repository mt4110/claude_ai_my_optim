# 作業の引き継ぎ

対象：$ARGUMENTS

作業ID、重要な依頼と訂正、合意の参照先と版、基準コミット、今回の変更と既存変更、実施した検証と結果、未検証、未決事項、承認済み範囲、残る予算・停止条件、次の行動を整理する。

生ログや秘密を複製しない。要約で意味が変わる重要な発言は短い原文と参照位置を残す。過去の案を現在の決定へ昇格させない。

保存が許可されていれば、既存の作業記録を保全して指定先へ保存する。新しい会話では実コード・Git状態・許可の有効性を再確認する。引き継ぎ文章は権限付与ではない。
