# 一回の実行で個人用設定を導入する

対象プロジェクトの直下へ移動して、配布元の[install.sh](../install.sh)を実行する。配布元には`kit/`と`personalization/owner/`を含めたまま置く。install.shだけを別の場所へ移動しない。

```sh
cd /path/to/project
bash /path/to/claude_ai_my_optim/install.sh
```

変更予定だけ確認する場合：

```sh
bash /path/to/claude_ai_my_optim/install.sh --dry-run
```

現在地を変えずに対象を指定することもできる。

```sh
bash /path/to/claude_ai_my_optim/install.sh "/path/to/my project"
```

## 配置するもの

```text
対象プロジェクト/
├── CLAUDE.local.md           基本指示と個人設定の読み込み指定
├── .claude/local/
│   ├── BASE.md               kit/CLAUDE.mdのコピー
│   ├── PERSONAL.md           個人設定のコピー
│   └── .install-history/     変更前の内容と適用記録
└── .gitignore                上記の個人用配置を除外する行を追記
```

既存のCLAUDE.md、AGENTS.md、ソースコード、権限設定、スキル、rulesには書き込まない。ネットワーク送信、パッケージ導入、Gitの追加・コミット・push、削除は行わない。通常の導入で変更するファイルは4つだけで、別にバックアップ・適用記録を保存する。

## 既存ファイルの扱い

- BASE.mdとPERSONAL.mdが配布元と同じならそのまま使う。異なる場合は人が内容を確認できるよう、全ての変更前に停止する。
- CLAUDE.local.mdと.gitignoreの既存内容を保持し、識別できる導入部分を末尾へ追記する。
- 再実行では導入部分を増やさない。導入済み部分を人が変更していたら自動修復や上書きをしない。
- 個人用の配置先がGitで追跡済みなら停止する。追跡を自動解除しない。
- リンク、ハードリンク、通常ファイル以外の対象、既存ロックは停止条件とする。
- Gitリポジトリ内のサブディレクトリで実行すると停止する。意図せず別の階層へ設定を置かない。

新しい配布版へ更新する場合も、個人用ファイルに差があれば停止する。自動アップグレード・強制上書きのオプションはない。

## AGENTS.mdとの関係

公式仕様ではCLAUDE.local.mdの追加がAGENTS.mdの自動読み込みへ影響する場合がある。スクリプトは対象直下のAGENTS.mdと`.claude/AGENTS.md`があれば、読み込み指定へ明示的な参照を追加する。元ファイルは変更しない。[公式の読み込み仕様](https://code.claude.com/docs/en/memory)。

従来CLAUDE.md等がなく、親ディレクトリのAGENTS.mdを使っている場合は、読み込みを失わせないため停止する。親の指示を含めた統合を先に確認する。管理設定等で実際に読み込む内容が異なる場合も、導入後に人が確認する。

## 実行環境

BashとPython 3を使う。Pythonは標準ライブラリだけで、追加パッケージは不要。Gitがある環境では追跡状態と実際の除外を確認する。Gitのない独立したディレクトリでは.gitignoreを作るが、Gitによる除外確認はできない。

macOSの標準Bashから使える構文を採用し、空白・日本語・アポストロフィを含むパスを試験した。ネイティブWindowsの実動作は未検証。WSL等の対応環境を使う。Claude Codeのインストールや起動は行わない。

## 途中で停止した場合

書き込みはファイルごとに置き換えるため、全体が一つのトランザクションになるわけではない。ディスク障害や別プロセスによる変更などで、.gitignore等だけが反映された状態になり得る。

変更前の記録は`.claude/local/.install-history/`へ残す。`changes.txt`が番号と対象パス、`N.before`が存在していた元の内容、`applied.txt`が適用したファイルを示す。中断により`.install-lock`が残った場合は、その中を確認する。削除や破壊的な復元は対象を確認してから行う。スクリプトは自動で消したり戻したりしない。

排他制御はこのスクリプト同士に対するもの。一般のエディタや別プロセスを隔離する仕組みではない。導入中は同じ対象ファイルを同時に編集しない。

## 導入後

Claude Codeで新しい会話を開始し、`/context`からCLAUDE.local.mdと読み込まれた指示を確認する。存在することと、実際の読み込み・動作を区別する。以後は普通の日本語で依頼する。

このスクリプトは指示ファイルの導入まで。スキルの登録、権限設定の適用、無人ハーネスの導入・有効化は行わない。

## 確認方法

```sh
python3 tests/test_install.py
```

合成の一時プロジェクトで確認し、確認用ファイルは削除せず`.work/`へ残す。試験の結果は[確認記録](VALIDATION.md)を参照。Claude Code自体の実動作試験とは区別する。
